# 学習ワークフロー状態テンプレート

このテンプレートは、会話履歴に依存せず「いま何を扱い、次に何をするか」を一意に復元するための状態ファイル原本です。リポジトリでは `docs/study/learning-state.md` に複製して使用します。

詳細な計画・学習記録はRoadmap、Learning Plan、Progressを正とし、このファイルには現在地を指すポインタだけを記録します。

## 現在の状態

| 項目 | 値 |
| --- | --- |
| 状態スキーマ | `1` |
| 最終更新日 | `YYYY-MM-DD` |
| 現在の運用範囲 | `なし / roadmap / independent` |
| 現在のRoadmap Step ID | `<roadmap-step-id / なし>` |
| 現在のLearning Plan ID | `<learning-id / なし>` |
| 現在のPlan内Step | `<Step番号 / なし>` |
| 現在のフェーズ | `準備 / Planレビュー待ち / 学習待ち / 学習中 / Step完了承認待ち / Plan完了承認待ち / Roadmap完了承認待ち / 保留 / 復旧待ち / なし` |
| ユーザー確認待ち | `なし / <確認してもらう内容>` |
| 次に行う1アクション | `<具体的な1アクション>` |

## 復帰先

Roadmapから独立学習へ一時的に切り替える場合だけ使用します。通常はすべて `なし` とします。切替は運用範囲が `roadmap`、復帰先がすべて `なし` の安全な停止地点からだけ許可します。復帰先は1件とし、上書きや独立学習の入れ子を禁止します。

復帰先の運用範囲が `independent`、またはRoadmap上なのに復帰先が残っている場合は、残存情報を消さずに学習ワークフローの復旧手順へ進みます。正常な復帰ではRoadmapとの整合性を確認してから復帰先を `なし` に戻します。

| 項目 | 値 |
| --- | --- |
| 復帰先の運用範囲 | `roadmap / なし` |
| 復帰先Roadmap Step ID | `<roadmap-step-id / なし>` |
| 復帰先Learning Plan ID | `<learning-id / なし>` |
| 復帰先Plan内Step | `<Step番号 / なし>` |
| 復帰先フェーズ | `<フェーズ / なし>` |
| 復帰先のユーザー確認待ち | `<確認内容 / なし>` |
| 復帰時の1アクション | `<具体的な1アクション / なし>` |

## 整合性チェック

| 確認項目 | 結果 | 確認日 |
| --- | --- | --- |
| Roadmapの現在Stepと一致 | `一致 / 対象外 / 要復旧` | `YYYY-MM-DD` |
| Planの親Roadmap Stepと一致 | `一致 / 対象外 / 要復旧` | `YYYY-MM-DD` |
| PlanとProgressの学習IDが一致 | `一致 / 対象外 / 要復旧` | `YYYY-MM-DD` |
| PlanとProgressの現在Stepが矛盾しない | `一致 / 対象外 / 要復旧` | `YYYY-MM-DD` |

| 日付 | 遷移前 | 操作 | 遷移後 | 更新ファイル | ユーザー確認 |
| --- | --- | --- | --- | --- | --- |
| `YYYY-MM-DD` | `<状態>` | `<操作>` | `<状態>` | `<パス>` | `不要 / 確認済み` |

直近の状態遷移は、現在の状態へ至った理由を確認できる範囲で残します。詳細な学習履歴はProgressへ記録し、ここへ重複させません。
