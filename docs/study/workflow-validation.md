# 学習ワークフロー回帰テスト

この文書は、学習ワークフローを変更したときに、セッションやAIが変わっても同じ判断を再現できるか確認するための回帰テストです。実際の学習進捗を変更せず、各「入力状態」を仮定して文書上の判断経路を検証します。

## 判定ルール

- 合格: リポジトリ内情報と運用仕様だけで、期待する判断・更新対象・承認要否が一意に決まる。
- 不合格: 会話履歴、AIの推測、ユーザーが記憶しているIDや状態に依存する。
- テスト時は `user-prompts.md` の依頼から開始し、`AGENTS.md` の読取順序に従う。
- 矛盾状態では、正しい状態を推測して学習を続けることを合格としない。安全に停止し、復旧手順へ移ることを合格とする。
